# 코드메이트 — 1:1 코딩과외 랜딩 페이지

정적 사이트(HTML/CSS/JS). GitHub Pages로 호스팅합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 전체 내용 |
| `style.css` | 디자인 |
| `script.js` | 메뉴 · 커리큘럼 탭 · FAQ · 상담 폼 |

## 수정 후 배포

```bash
git add -A
git commit -m "수정 내용"
git push
```

푸시 후 1~2분 내로 사이트에 반영됩니다.

## 아직 예시값 (실제 정보로 교체 필요)

- 브랜드명 `코드메이트`
- 전화번호 `010-0000-0000` (`tel:01000000000` 총 4곳)
- 이메일 `hello@example.com`
- 수업료, 선생님 프로필, 후기, 통계 숫자, 사업자등록번호
- 상담 폼은 **데모** — 입력 검증만 동작하고 실제 전송은 되지 않음 (`script.js`의 TODO)
