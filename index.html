CURRICULUM

목표별 커리큘럼

아래는 표준안이며, 상담 후 학생에 맞게 조정됩니다.

총 12~16회주 1~2회 · 90분초등 고학년~성인
  1. 1~3회개발 환경 설치, 변수·조건·반복문. 첫날부터 실행되는 코드를 만듭니다.
  2. 4~7회함수와 자료구조(리스트·딕셔너리). 계산기, 단어장 같은 미니 프로그램 제작.
  3. 8~11회파일 입출력, 예외 처리, 외부 라이브러리 사용. 엑셀 자동화·크롤링 맛보기.
  4. 12~16회개인 프로젝트 1개 완성 + 발표. 포트폴리오로 남습니다.
총 16~20회주 1~2회 · 90분중등~성인
  1. 1~4회HTML·CSS 구조와 레이아웃. 내 소개 페이지를 직접 만들어 배포까지.
  2. 5~9회자바스크립트 기본, DOM 조작, 이벤트. 동작하는 UI 만들기.
  3. 10~15회API 연동, 비동기 처리, 반응형. 실제 데이터를 쓰는 서비스 화면 구현.
  4. 16~20회깃허브 관리 + 실제 도메인 배포. 링크로 공유 가능한 결과물 완성.
총 20회~주 1~2회 · 90분중등~고등
  1. 기초시간복잡도, 배열·문자열·정렬. 백준 브론즈~실버 구간 정착.
  2. 핵심완전탐색, 그리디, DFS/BFS, 이분탐색. 유형별 풀이 패턴 정리.
  3. 심화DP, 그래프, 자료구조 응용. 정보올림피아드·정보과학 기출 분석.
  4. 실전시간 제한 모의고사 + 오답 리뷰. 대회 직전 컨디셔닝.
총 12회~주 1~2회 · 90분대학생 · 직장인
  1. 1~4회코딩테스트 빈출 유형 진단 및 약점 파악. 언어별 문법 최적화.
  2. 5~8회기업별 기출 유형 집중 훈련. 풀이 시간 단축 전략.
  3. 9~12회실전 모의 + 라이브 코딩 대비. 풀이 과정을 말로 설명하는 연습.
  4. 선택포트폴리오 코드 리뷰, 기술 면접 질문 대비, 이력서 프로젝트 다듬기.

FAQ

자주 묻는 질문

컴퓨터를 잘 못 다뤄도 시작할 수 있나요?

네. 첫 수업에서 개발 환경 설치부터 함께 진행합니다. 마우스와 키보드만 쓸 줄 알면 충분하고, 필요한 프로그램은 모두 무료입니다.

몇 살부터 배울 수 있나요?

보통 초등 4학년(만 10세)부터 권장합니다. 그 아래는 블록 코딩(스크래치·엔트리)으로 시작해 텍스트 코딩으로 넘어가는 과정을 제안드립니다.

수업 요일이나 시간을 바꿀 수 있나요?

수업 24시간 전까지 알려주시면 자유롭게 조정 가능합니다. 시험 기간에는 일시 정지 후 재개하는 학생도 많습니다.

선생님이 안 맞으면 어떻게 하나요?

언제든 교체 요청하실 수 있고, 추가 비용은 없습니다. 첫 수업 후 불만족하시면 전액 환불해 드립니다.

화상 수업도 효과가 있나요?

코딩은 화면 공유로 코드를 같이 보며 진행하기 때문에 대면과 차이가 거의 없습니다. 오히려 녹화본이 남아 복습에는 더 유리합니다.

노트북이 꼭 필요한가요?

데스크톱도 괜찮습니다. 다만 사양이 낮아도 대부분 문제없으며, 필요하면 상담 때 환경에 맞는 대안을 안내드립니다.
